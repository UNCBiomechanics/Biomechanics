Filter Lab

Paste a column of signal values, or two columns of time and value, apply a Butterworth low-pass / high-pass (1st–4th order) or a notch filter, see the before/after in both domains, then copy the filtered column straight back out to Excel. Runs entirely in your browser — nothing is uploaded anywhere.

One column = amplitude values only (set the sampling rate below). Two columns = time and value (sampling rate is worked out automatically from the time column).

Filter settings

Order sets how sharply the filter rolls off past the cutoff — higher order cuts faster but rings more. 4th order is the common default for kinematic data (e.g. Winter's recommended cutoff).

Q sets how narrow the notch is (Q = center frequency ÷ bandwidth). Higher Q removes less of the surrounding signal; lower Q removes a wider band around the center frequency.

Select all and copy, or use the button below. Output matches your input layout — a single column if you pasted one, or "time   value" pairs if you pasted two — so it drops straight into an Excel column (or two).

Notes: filters are designed directly as digital IIR filters (Butterworth via pole placement + bilinear transform; notch via a standard 2nd-order band-stop) — no external DSP library. "Zero-phase" runs the filter forward, then backward, and removes the time-shift that a single causal pass would introduce, at the cost of not being usable in real time; this is the standard treatment for kinematic/force data. The ends of the signal are padded by reflection before filtering to reduce edge transients, then trimmed back to your original length before being handed back to you.
