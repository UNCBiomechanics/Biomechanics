Residual Analysis — Choosing a Cutoff

Winter's residual method: filter the raw signal at many cutoff frequencies and measure the RMS residual (RMS of filtered − raw) at each one. At low cutoffs you're removing real signal, so the residual is high; once you're only removing noise, the curve flattens out — the "knee" marks a defensible cutoff choice.

Shows |H(f)| for each Butterworth/notch filter above (moving RMS isn't a linear filter, so it has no frequency response curve). The dashed gray line marks −3 dB / half power.

Notes: RMS in the comparison table is the whole-record root-mean-square of that comparison's signal, sqrt(mean(x²)) — a DC offset in your data will inflate it. That is different from the residual RMS in the analysis above, which is sqrt(mean((filtered − raw)²)) — the quantity Winter's method actually plots against cutoff frequency. "Half-power" is the frequency where a filter's magnitude response crosses 0.7071 (−3 dB), found numerically for each filter design rather than assumed equal to the cutoff you typed — for Butterworth filters they should match closely; for the notch filter, the table instead reports the null frequency and the approximate −3 dB bandwidth (center frequency ÷ Q). A causal (non-zero-phase) filter shifts your signal in time, more so at higher order and lower cutoff — adding both a zero-phase and causal version of the same filter to the comparison makes that shift directly visible on the time-domain chart.
